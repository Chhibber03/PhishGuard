# PhishGuard
A hybrid machine learning-based system that detects phishing websites using URL features, and classifies SMS/Email messages for spam and phishing threats using Natural Language Processing. Built with Python and Flask, trained on phishing site URLs and Indian SMS Spam datasets.

## Features
- **URL Analyzer:** Detects phishing and legitimate websites from direct URL input.
- **Text Link Analyzer:** Classifies entire SMS/Email messages as Spam or Ham.
  - Automatically extracts and scans embedded URLs.
  - Detects suspicious semantic tokens (e.g., "win", "prize", "urgent", "otp").
  - Calculates a comprehensive Message Risk Score (0-100) based on NLP confidence, URL analysis, and heuristics.
- Trained on large datasets of phishing URLs and SMS spam.
- Uses Machine Learning models including Multinomial Naive Bayes and TF-IDF Vectorization.
- Interactive, multi-tab web interface built with Flask.
- Highlights results with color-coded risk labels (Low, Moderate, High, Critical).

## How It Works
- **URL Analysis:** The user enters a website URL, which is cleaned, vectorized, and passed through the trained URL model to predict if the site is phishing or legitimate.
- **Text Analysis:** The user pastes a full message. The backend uses the trained SMS model to classify the text, extracts any contained links, scans those links with the URL model, evaluates semantic tokens, and aggregates the data into a final Risk Score.

## Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/alpha-coder21/PhishGuard.git
   cd PhishGuard
   ```
2. Create and activate a Python virtual environment:
   ```bash
   python -m venv env
   # Windows:
   env\Scripts\activate
   # macOS/Linux:
   source env/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Place the following URL model files in the project root:
   - `model.pkl` (trained ML model)
   - `vectorizer.pkl` (CountVectorizer)
   - `mnb.pkl` (Naive Bayes model)
   - `phishing_site_urls.csv` (Dataset: https://www.kaggle.com/datasets/taruntiwarihp/phishing-site-urls)
5. Generate the SMS text classification models:
   - Run the training script (it will automatically download a fallback SMS dataset if needed, or you can supply the [India Spam SMS dataset](https://www.kaggle.com/datasets/junioralive/india-spam-sms-classification)):
     ```bash
     python train_sms_model.py
     ```
   - This will generate `sms_model.pkl` and `sms_vectorizer.pkl`.

## Usage
1. Start the Flask app:
   ```bash
   python app.py
   ```
2. Open your browser and go to `http://127.0.0.1:5000/`
3. Use the **URL Analyzer** tab to check individual links, or the **Text Link Analyzer** tab to evaluate full messages.

## Examples
- **URL Analyzer (Phishing):**
  - Input: `yeniik.com.tr/wp-admin/js/login.alibaba.com/login.jsp.php`
  - Output: `This is a Phishing Website !!` (shown in red)
- **URL Analyzer (Legitimate):**
  - Input: `www.youtube.com/`
  - Output: `This is a Legitimate Website !!` (shown in green)
- **Text Link Analyzer (Spam):**
  - Input: `Congratulations! You won ₹25,000 cash prize. Click http://fake-link.com now!`
  - Output: `Message Type: Spam | Risk Label: Critical | Suspicious Tokens: congratulations, won, prize, click`
